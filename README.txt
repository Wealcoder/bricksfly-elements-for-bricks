### Why Bricks Builder Needs More
Bricks Builder is one of the fastest, cleanest page builders available — but it's intentionally minimal. Many essential design elements, advanced animations, ready-made templates, and workflow extensions aren't included by default.
Creating advanced scroll animations, building common UI patterns, or designing modern animated layouts often means writing custom code or stitching together multiple third-party tools.
The Bricksfly solves this by bringing everything you need directly inside Bricks Builder — elements, extensions, animations, and templates — in one lightweight plugin.
### The Complete Toolkit That Enhances Bricks Builder
The Bricksfly is built around four pillars that complete what Bricks gives you out of the box:
- **Templates** — 20+ professionally designed Bricks website templates plus preset animation templates to launch faster.

- **Extensions** — 15+ smart extensions that supercharge your workflow with GSAP animations, cursor effects, tooltips, and more.

== Installation ==
= Minimum Requirements =
* WordPress 6.6 or greater
* PHP version 7.4 or greater
* MySQL version 5.7 or greater
* Bricks theme installed and active
= Recommended Requirements =
* PHP version 8.3 or greater
* MySQL version 5.7 or greater
* WordPress Memory limit of 128 MB or greater (1024 MB or higher is preferred)
= Installation =
Note: This plugin requires the Bricks theme to function. Please ensure Bricks is installed and activated before proceeding.
1. Install the plugin directly from the WordPress Plugins screen, or manually upload the plugin files to /wp-content/plugins/bricks-addons directory.
2. Activate the plugin from the Plugins section in your WordPress dashboard.
3. Access all settings via the admin sidebar under **The Bricksfly**.
4. Find all elements categorized inside the Bricks editor under the **The Bricksfly** group.
For any questions, visit our FAQ page or reach out via our Contact Form. 🚀

== External Services ==

The plugin uses the services below only under the conditions described for each service. Installing or activating the plugin does not by itself send account details, post content, or form submissions to these providers. Normal internet request data such as an IP address, browser or WordPress user agent, and referrer may still be received by a provider when a connection is made.

= 1. Template library and starter-template services =

Service domains: `https://www.themecrowdy.com/` and `https://block.animation-addons.com/`

* **What the services are used for:** They provide template menus, template and section listings, downloadable Bricks template data, and media referenced by an imported starter site.
* **When requests are made:** Template listings are requested when an administrator opens the Bricksfly template screens or the template library in the Bricks editor. Template files and referenced media are downloaded only after an administrator chooses to import or insert a template.
* **Data sent:** Standard request information such as the server or administrator IP address, browser or WordPress user agent, site URL or referrer, plus request parameters such as search text, filters, page number, template type, template ID, and the selected template descriptor. The plugin does not intentionally send post content, passwords, or WordPress user account details. During an import, the site also requests media URLs supplied by the selected template; those media hosts receive the normal request information needed to deliver the files.
* **Provider:** Wealcoder / Animation Addons. [Terms and Conditions](https://animation-addons.com/terms-and-conditions/) | [Privacy Policy](https://animation-addons.com/privacy-policy/)

= 2. Wealcoder content services =

Service domains: `https://store.wealcoder.com/`, `https://wealcoder.com/`, and `https://crowdytheme.com/`

* **What the services are used for:** The store supplies the public plugin changelog shown in the Bricksfly dashboard. A Wealcoder-hosted demonstration video is the default media URL for the Video Mask element. CrowdyTheme supplies the article thumbnails displayed in the dashboard's Latest Blogs section.
* **When requests are made:** The changelog is requested when an administrator opens the Bricksfly dashboard and no cached changelog is available. The demonstration video is requested by a visitor's browser only when a page contains a Video Mask element that still uses that default URL. Article thumbnails are requested when the Bricksfly dashboard is displayed.
* **Data sent:** For the changelog, standard server request information including the server IP address and WordPress user agent, which can contain the site URL. For videos and thumbnails, the visitor or administrator IP address, browser user agent, referrer, and normal HTTP request headers. The free plugin does not send license keys to these services.
* **Provider:** Wealcoder / Animation Addons. [Terms and Conditions](https://animation-addons.com/terms-and-conditions/) | [Privacy Policy](https://animation-addons.com/privacy-policy/)

= 3. YouTube embedded player =

Service information: https://developers.google.com/youtube/player_parameters

* **What the service is used for:** Displays YouTube videos selected in the Video Box and Video Box Slider elements and tutorial videos opened from the Bricksfly dashboard.
* **When requests are made:** A visitor's browser connects to YouTube when a page containing a configured YouTube embed is loaded. An administrator's browser connects when a YouTube tutorial dialog is opened in the dashboard.
* **Data sent:** The configured video ID and normal browser request information, including the visitor's IP address, browser user agent, referrer, and any cookies that Google is permitted to read or set.
* **Provider:** Google / YouTube. [Terms of Service](https://www.youtube.com/t/terms) | [Privacy Policy](https://policies.google.com/privacy)

= 4. Vimeo embedded player =

Service domain: `https://player.vimeo.com/`

* **What the service is used for:** Displays a Vimeo video selected in the Video Box or Video Box Slider element.
* **When requests are made:** Only when a visitor loads a page containing an element configured with a Vimeo video URL.
* **Data sent:** The configured video ID and normal browser request information, including the visitor's IP address, browser user agent, referrer, and any cookies that Vimeo is permitted to read or set.
* **Provider:** Vimeo. [Terms of Service](https://vimeo.com/terms) | [Privacy Policy](https://vimeo.com/privacy)

= 5. Social sharing services =

* **What the services are used for:** The Post Social Share element creates share links for Facebook, X/Twitter, LinkedIn, Pinterest, Reddit, Tumblr, and Blogger.
* **When requests are made:** No request is made merely because the share buttons are displayed. A visitor connects to the selected service only after clicking its share button.
* **Data sent:** Depending on the selected service, the current page permalink and title, and for Pinterest the featured-image URL. The service also receives normal browser request information such as the visitor's IP address, browser user agent, referrer, and cookies.

= Administrator-supplied remote media =

Some video controls allow a site administrator to enter a direct media URL instead of using the WordPress Media Library. If an administrator chooses a third-party URL, visitors viewing that element connect to the administrator-selected host and send the normal browser request information required to retrieve the media. The identity, terms, and privacy policy of that host depend on the URL selected by the administrator.
